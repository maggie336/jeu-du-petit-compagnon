# Jeu du petit compagnon

Jeu d'animal virtuel en français : Rumi, le chat sorcier blanc très poilu.

## Jouer

Ouvrez `jeu.html` dans votre navigateur. Aucune installation, aucun compte requis.

Prenez soin de Rumi : lavez-le, nourrissez-le, donnez-lui à boire et
faites-le dormir avant que ses barres de besoins se vident (5 minutes),
dans un jardin tout en couleurs avec son amie sorcière. Chaque soin à
temps rapporte des pièces — mais attention à la barre « pas content » :
quand elle est pleine, on perd toutes ses pièces !

## Contenu du dépôt

- `SKILL.md` : la fiche du skill pour les assistants IA (comment lancer le jeu).
- `jeu.html` : le jeu complet, interface graphique inchangée.
- `assets/` : les images du jeu.
